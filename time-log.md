# Care Log — Time Log

**Important caveat, read before trusting these numbers:** Claude can only see what happens inside
a conversation. This log can track when a Care Log conversation started (and, if you tell me when
you're wrapping up, roughly how long it ran) — it cannot see any time you spend working on this
outside of talking to Claude (your own coding, meetings, research, thinking in the shower, etc.),
and it can't tell active work from a conversation left open in the background. Treat this as a
rough lower bound on conversation time, not a real time-tracking system. If you want accurate
totals, the honest move is a separate time tracker you control — I'm glad to help pick one, but I
shouldn't be the source of truth for something this easy for me to get wrong.
